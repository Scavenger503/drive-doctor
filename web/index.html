Where do I find this page?
  • Synology DSM: Storage Manager › HDD/SSD › select the drive › Health Info
  • UGREEN UGOS: Storage › Hard drive › select the drive › S.M.A.R.T. information
  • Asustor ADM: Storage Manager › Disk › select the drive › S.M.A.R.T. Info
  • Windows: the free CrystalDiskInfo app

How do I get this report?

On Linux, a NAS, or a Mac with smartmontools installed, run sudo smartctl -a /dev/sda (change sda to your drive) and paste everything it prints. On Synology, use sudo smartctl -a -d sat /dev/sata1.

Serial numbers and drive IDs are removed before anything is analyzed.

Verdicts come from fixed health rules. Explanations are written by open AI models running on AMD GPUs through AMD Token Lab. Always keep a backup.
